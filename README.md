📊 Sales Data Analysis & Visualization Mini-Project
🚀 Project Overview
This mini-project focuses on cleaning, analysing, and visualizing sales data using Microsoft Excel and Power BI. The project was completed to gain practical knowledge of data analysis tools and understand how raw data can be transformed into meaningful insights and interactive dashboards.

🎯 Project Objectives
* To clean and organize raw sales data using Excel.
* To perform data analysis using Excel formulas and functions.
* To use IF conditions, VLOOKUP, and XLOOKUP for data analysis.
* To apply Conditional Formatting to identify important values.
* To perform Descriptive Statistical Analysis.
* To create Pivot Tables and Pivot Charts for summarizing data.
* To develop interactive dashboards using Power BI.
* To identify important trends, patterns, and business insights.
* To provide useful recommendations based on the analysis.

🔄 Project Workflow
Raw Data → Data Cleaning → Data Formatting → Formula & Condition Analysis → Conditional Formatting → Descriptive Statistics → Pivot Tables → Excel Dashboard → Power BI Dashboards → Insights & Recommendations

📈 Excel Analysis

In Excel, the raw dataset was first cleaned and organized. Formulas and functions were used to calculate and analyse the required values. IF conditions, VLOOKUP, XLOOKUP, and Conditional Formatting were used to identify and highlight important information.

Descriptive statistics were performed for Unit Price, Discount, and Sales Amount using measures such as Mean, Median, Mode, Standard Deviation, Variance, Minimum, Maximum, Range, Sum, and Count.

Pivot Tables were then created to analyse category-wise sales, segment-wise sales and profit, city-wise sales and profit, product performance, yearly sales trends, and discount versus profit.

📊 Power BI Dashboards

Five interactive dashboards were created in Power BI:

1. Sales Overview

Provides an overall view of sales, units sold, customer segments, yearly sales trends, city-wise sales, and product performance.

2. Profit & Discount Analytics

Analyses profit, discount impact, profit per order, profit per unit, monthly profit, and product-wise profit.

3. Geographical & Product Analysis

Helps analyse sales and profit based on geographical areas, cities, products, and time periods. It provides interactive filtering for deeper analysis.

4. Employee Information

Provides detailed customer/employee-related information such as city, segment, product category, sales, profit, discount, delivery status, bonus, and units sold. A navigation button is used to move from the Sales Overview to the detailed information page.

5. Key Insights & Recommendations

Summarizes the major findings from the analysis and provides recommendations for better decision-making, employee management, performance improvement, training, and workforce planning.
